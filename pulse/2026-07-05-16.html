Agents Should Record the Demo, Not Just Ship the Diff

Simon Willison's Newsletter

Simon Willison released shot-scraper video, a Playwright-backed command that lets an agent follow a YAML storyboard and record a product demo as part of the work. The important bit is not the video file; it is the workflow standard it implies. Agents can be asked to review the branch, run the tool help, create a demo database, exercise the feature, and leave behind an artifact humans can inspect quickly.

My take: this is a clean pattern for agentic product work. A useful agent should not merely say that a UI path works. It should produce evidence: screenshots, videos, logs, traces, and reproducible scripts. For Hiro-style financial workflows, that same standard matters even more because trust depends on seeing exactly what the agent did.

"I really like this pattern where the --help output for a command provides enough detail that a coding agent can use it - it works kind of like bundling a SKILL.md file directly inside the tool."

Why it matters: This is directly relevant to building reliable financial agents: make tools self-describing, then require the agent to produce verifiable artifacts instead of prose-only status updates.
